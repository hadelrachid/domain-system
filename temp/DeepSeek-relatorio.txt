### 3. `docs/arquitetura.html` - Arquitetura

```html
🏗️ Como funciona o Kernel?

Componentes Core:
🔹 Router (Roteador) → Mapeia URLs para Controllers
🔹 EventDispatcher (Gatilhos) → Gerencia Hooks e Filtros
🔹 PluginManager → Lê plugins, valida e ativa
🔹 ThemeManager → Gerencia Front-end com SSR

Fluxo de Requisição:
1. Usuário acessa o navegador
2. public/index.php recebe o pedido
3. bootstrap.php carrega o Container
4. PluginManager ativa os Plugins
5. Router avalia a URL
6. Controller específico é executado
7. Banco é acessado via PDO (QueryBuilder)
8. Resposta (HTML ou JSON) é devolvida
```

### 4. `docs/contratos.html` - Contratos SOLID

```html
📜 Contratos e Interfaces (SOLID)

Princípio da Segregação de Interfaces (ISP):
- Classes não dependem umas das outras
- Dependem de Contratos (Interfaces)

PluginInterface:
public function register(): void;
public function boot(): void;
public function activate(): void;
public function deactivate(): void;
public function uninstall(): void;

ExtractorInterface:
public function extract(string $archivePath, string $destinationPath): string;
```

### 5. `docs/criando-plugins.html` - Guia Prático

```html
🧩 Guia: Como Construir um Plugin

Passo 1: Crie a Estrutura de Pastas
src/Plugins/meu_plugin/

Passo 2: Arquivo de Manifesto (plugin.json)
{
    "name": "meu_plugin",
    "version": "1.0.0",
    "description": "Meu primeiro plugin customizado",
    "namespace": "DomainSystem\\Plugins\\meu_plugin\\",
    "entrypoint": "Plugin"
}

Passo 3: A Classe Principal (Plugin.php)
class Plugin extends AbstractPlugin
{
    public function register(): void
    {
        // Registrar rotas
        // Adicionar ao menu
    }
}

Passo 4: Ativando via Sistema
→ Painel Admin > Plugins > Ativar
```
