## 📋 O QUE O PROJETO OFERECE PARA A COMUNIDADE

### 1. **Arquitetura SOLID 10/10**

| Princípio | Status | Descrição |
|-----------|--------|-----------|
| **SRP** | ✅ | Cada classe tem uma única responsabilidade |
| **OCP** | ✅ | Aberto para extensão via plugins, eventos e filtros |
| **LSP** | ✅ | Substituição de implementações via interfaces |
| **ISP** | ✅ | Interfaces pequenas e específicas |
| **DIP** | ✅ | Dependências injetadas via Container |

### 2. **Sistema de Plugins (WordPress-like)**

```php
// Qualquer pessoa pode criar um plugin com apenas 2 arquivos:
// 1. plugin.json
{
    "name": "meu-plugin",
    "version": "1.0.0",
    "description": "Meu plugin incrível",
    "dependencies": ["database"]
}

// 2. Plugin.php
class Plugin extends AbstractPlugin
{
    public function register(): void
    {
        // Registrar rotas
        addListener('router.register', function($router) {
            $router->addRoute('GET', '/admin/meu-plugin', [MeuController::class, 'index']);
        });

        // Adicionar ao menu
        addFilter('admin.menu', function($menu) {
            $menu[] = ['title' => 'Meu Plugin', 'url' => '/admin/meu-plugin'];
            return $menu;
        });
    }
}
```

### 3. **Sistema de Eventos e Filtros (Hooks)**

```php
// Disparar eventos
$dispatcher->dispatch('meu_evento', $dados);

// Escutar eventos
$dispatcher->addListener('meu_evento', function($dados) {
    // Fazer algo com os dados
});

// Aplicar filtros
$valor = $dispatcher->applyFilters('meu_filtro', $valor, $param1);

// Adicionar filtros
$dispatcher->addListener('meu_filtro', function($valor, $param1) {
    return $valor . ' modificado';
}, 10);
```

### 4. **Motor de Temas (SSR)**

```php
// Controladores renderizam templates
return $theme->render('admin/meu-plugin/index', $dados);

// Templates usam helpers
<?= $this->getHeader() ?>
    <h1><?= $titulo ?></h1>
    <?php foreach ($itens as $item): ?>
        <li><?= $item['nome'] ?></li>
    <?php endforeach; ?>
<?= $this->getFooter() ?>
```

### 5. **QueryBuilder Fluent (SQL Injection Safe)**

```php
// Buscar usuários
$users = $db->table('users')
    ->where('active', '=', 1)
    ->where('role', '=', 'admin')
    ->get();

// Inserir
$id = $db->table('users')->insert([
    'name' => 'João',
    'email' => 'joao@email.com'
]);

// Atualizar
$db->table('users')
    ->where('id', '=', $id)
    ->update(['status' => 'active']);

// Deletar
$db->table('users')
    ->where('id', '=', $id)
    ->delete();
```

## 📝 GUIA PARA CONTRIBUIDORES

### Como Contribuir

1. **Fork o repositório**
2. **Clone seu fork**
3. **Crie uma branch para sua feature**
4. **Faça suas alterações seguindo os padrões SOLID**
5. **Escreva testes para suas alterações**
6. **Envie um Pull Request**

### Padrões de Código

```php
// 1. Use injeção de dependências
class MeuController
{
    private ThemeManager $theme;
    private QueryBuilder $db;

    public function __construct(ThemeManager $theme, QueryBuilder $db)
    {
        $this->theme = $theme;
        $this->db = $db;
    }
}

// 2. Use interfaces
class MeuPlugin extends AbstractPlugin implements PluginInterface
{
    // ...
}

// 3. Use eventos para extensibilidade
$dispatcher->dispatch('meu_evento', $dados);

// 4. Use filtros para modificação
$valor = $dispatcher->applyFilters('meu_filtro', $valor);
```

### Como Criar um Novo Plugin

```bash
# 1. Crie a pasta do plugin
mkdir src/Plugins/meu-plugin

# 2. Crie o plugin.json
cat > src/Plugins/meu-plugin/plugin.json << EOF
{
    "name": "meu-plugin",
    "version": "1.0.0",
    "description": "Meu plugin incrível",
    "dependencies": ["database", "system-admin"]
}
EOF

# 3. Crie o Plugin.php
cat > src/Plugins/meu-plugin/Plugin.php << EOF
<?php
namespace DomainSystem\Plugins\meu-plugin;

use DomainSystem\Core\Plugin\AbstractPlugin;

class Plugin extends AbstractPlugin
{
    public function register(): void
    {
        // Sua lógica aqui
    }
}
EOF

# 4. Instale via painel ou ative manualmente
php src/Plugins/system-admin/scripts/activate_plugin.php meu-plugin
```
