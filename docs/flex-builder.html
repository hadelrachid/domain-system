🏗️ Flex Builder FSE (Full Site Editing)

Motor Visual em Blocos Semânticos, CSS Grid de 12 Colunas e Auto-Reflow Responsivo (v2.7.0)

Visão Geral

O Flex Builder (src/Core/Theme/Parts + src/Plugins/flextheme) é o construtor visual de cabeçalhos (header), rodapés (footer) e seções centrais (section) do Domain-System. Ele foi projetado com compilação unificada para garantir paridade exata entre o editor ao vivo e a página pública renderizada.

Principais Recursos

  • Caminho Único de Compilação (ThemePartCompilerInterface): Tanto o preview do Studio quanto o frontend público passam pelo mesmo compilador, eliminando divergências visuais.
  • Validação Estrutural Pré-Persistência (ThemePartValidatorInterface): Valida tipos de partes, presets de colunas e compatibilidade de blocos (getAllowedPartTypes()) antes de salvar.
  • Visibilidade Responsiva em 4 Resoluções com Auto-Reflow: Controle individual por elemento em Desktop (100%), Laptop (1024px), Tablet (768px) e Mobile (375px). Quando todos os elementos de uma coluna ficam ocultos em uma resolução, a coluna colapsa automaticamente e o CSS Grid redistribui o espaço entre as colunas visíveis.
  • Menus Hierárquicos & Gaveta Mobile (ds-mobile-drawer): Construtor drag-and-drop horizontal de submenus e 8 estilos de botão hambúrguer customizáveis.
  • Isolamento de Temas Nativos ("flex_builder": false): Quando um tema dedicado de e-commerce (como rachidd_store no DomainDrop) possui cabeçalho e rodapé nativos próprios, o Flex Builder detecta a diretiva via ThemeDiscoveryService::supportsFlexBuilder(), bloqueia a substituição acidental de cabeçalho/rodapé e exibe um aviso claro no editor.

Extensão via BlockProviderInterface

Qualquer plugin pode registrar blocos visuais próprios no Flex Builder sem modificar o núcleo, implementando BlockInterface e BlockProviderInterface (como o bloco de vitrine DropshipShowcaseBlock do DomainDrop).
