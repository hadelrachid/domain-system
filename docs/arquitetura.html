Arquitetura do Motor

Como funciona o Kernel?

O Domain-System é inicializado via bootstrap.php. Nesse momento, o Container de Injeção de Dependência é montado. O Container é o cérebro que gerencia a criação de todas as classes importantes, garantindo que ninguém crie objetos do jeito errado com "new" espalhados pelo código.

Componentes Core

  • SessionManager (Gerenciador de Sessões): Autoridade única sobre o armazenamento em memória do usuário (evita superglobais como $_SESSION soltas pelo código).
  • Router (Roteador Gatekeeper): Mapeia URLs para Controllers e age como Porteiro (ACL), validando papéis antes mesmo de chamar os controladores.
  • EventDispatcher (Gatilhos): Gerencia Ações (Hooks) e Filtros. Se um plugin quer alterar o menu, ele "escuta" o evento admin.menu.
  • PluginManager: Lê a pasta src/Plugins/, valida o plugin.json e chama o método register() de cada plugin ativo.
  • ThemeManager: Gerencia o Front-end. Intercepta as requisições que não são da API ou do Painel, e entrega visual usando Server-Side Rendering (SSR).

Fluxo de Requisição (Life-cycle)

1. Usuário acessa o navegador.
2. public/index.php recebe o pedido.
3. bootstrap.php carrega o Container e os Serviços (Database, EventDispatcher, SessionManager).
4. PluginManager ativa os Plugins (cada plugin injeta suas Rotas e Repositórios).
5. Router avalia a URL e verifica as Regras de Acesso (ACL).
6. Controller específico é instanciado via Injeção de Dependência.
7. O Controller acessa a Camada de Repositórios (Repository Pattern) que manipula o banco via PDO.
8. A resposta puramente HTTP (Response) é devolvida ao usuário.
