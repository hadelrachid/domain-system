🤖 Master AI Contract Guide

Architectural Guidelines for Safe AI-Assisted Plugin & Theme Generation (v2.7.0)

Why an AI Contract Guide?

Domain-System is architected to work seamlessly with AI coding assistants (Gemini, Claude, ChatGPT, Copilot, Cursor). To ensure AI-generated code strictly respects our SOLID and Clean Architecture boundaries, every extension follows explicit interface contracts.

1. Non-Negotiable Architectural Rules

  • Zero Superglobals in Controllers: Never access $_GET, $_POST, $_SESSION, $_FILES, or $_SERVER directly inside Controllers. Always use constructor-injected Request ($request->input(), $request->json()) and SessionManagerInterface (enforced by NoSuperglobalsInControllersTest).
  • Dependency Inversion (DIP): Services and Controllers depend strictly on interfaces under Contracts/, never on concrete PDO repositories or raw external HTTP clients.
  • Ring Isolation (Ring 0 vs. Ring 3): Plugins in src/Plugins/ (Ring 3) interact with the Kernel (Ring 0) exclusively via OsExtensionInterface (osRegister and osBoot) and hooks.
  • Database-Agnostic SQL (MySQL & SQLite): PDO repositories must use standard SQL compatible with both MySQL/MariaDB (production) and in-memory SQLite (PHPUnit test suite).

2. CLI Boilerplate Generator

To scaffold a compliant plugin structure automatically, run:

php os-cli.php make:plugin my_plugin

This generates plugin.json (version 2.7.0 / os_version: 2.7), Plugin.php implementing OsExtensionInterface, and the auto-discovered manual module manual/module.php (ManualModuleInterface).

3. Standard Plugin Directory Tree

src/Plugins/my_plugin/
├── plugin.json
├── Plugin.php
├── Contracts/
│   └── MyRepositoryInterface.php
├── Repositories/
│   └── PdoMyRepository.php
├── Services/
│   └── MyService.php
├── Controllers/
│   └── MyController.php
├── manual/
│   └── module.php
└── views/
    ├── admin/
    └── front/

4. Automated Verification

Before deploying any AI-assisted change, run the architecture and unit test suites:

php phpunit.phar tests/Architecture
php phpunit.phar
