Engine Architecture

How does the Kernel work?

The Domain-System is initialized via bootstrap.php. At this moment, the Dependency Injection Container is assembled. The Container is the brain that manages the creation of all important classes, ensuring no one creates objects the wrong way with "new" scattered throughout the code.

Core Components

  • Router: Maps URLs to Controllers (e.g., /admin/settings calls the SettingsController::index method).
  • EventDispatcher (Triggers): Manages Actions (Hooks) and Filters. If a plugin wants to change the menu, it "listens" to the admin.menu event.
  • PluginManager: Reads the src/Plugins/ folder, validates plugin.json, and calls the register() method of each active plugin.
  • ThemeManager: Manages the Front-end. Intercepts requests that are not from the API or Dashboard, and delivers visuals using Server-Side Rendering (SSR).

Request Flow (Life-cycle)

1. User accesses the browser.
2. public/index.php receives the request.
3. bootstrap.php loads the Container and Services (Database, EventDispatcher).
4. PluginManager activates the Plugins (each plugin injects its Routes).
5. Router evaluates the URL.
6. Specific Controller is executed.
7. The database is accessed via secure PDO (QueryBuilder).
8. The response (HTML or JSON) is returned to the user.
