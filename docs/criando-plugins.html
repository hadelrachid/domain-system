Guia: Como Construir um Plugin

Passo 1: Crie a Estrutura de Pastas

Acesse o diretório src/Plugins/ e crie uma pasta (ex: meu_plugin).

Passo 2: Arquivo de Manifesto (plugin.json)

Crie um arquivo plugin.json. Ele diz ao motor quem você é.

{
    "name": "meu_plugin",
    "version": "1.0.0",
    "description": "Meu primeiro plugin customizado",
    "namespace": "DomainSystem\\Plugins\\meu_plugin\\",
    "entrypoint": "Plugin"
}

Passo 3: A Classe Principal (Plugin.php)

Crie o arquivo Plugin.php. Ele é o coração do seu sistema.

<?php
namespace DomainSystem\Plugins\meu_plugin;

use DomainSystem\Core\Plugin\AbstractPlugin;
use DomainSystem\Core\Routing\Router;

class Plugin extends AbstractPlugin
{
    public function register(): void
    {
        // 1. Ouvir evento para registrar rotas
        $events = $this->container->make(\DomainSystem\Core\Events\EventDispatcher::class);
        
        $events->addListener('router.register', function(Router $router) {
            $router->addRoute('GET', '/admin/meu-plugin', function() {
                echo "
Olá do Meu Plugin!
";
            });
        });

        // 2. Colocar botão no Menu do Painel
        $events->addListener('admin.menu', function($menu) {
            $menu[] = [
                'title' => 'Meu Plugin',
                'url' => '/admin/meu-plugin',
                'icon' => '⭐'
            ];
            return $menu;
        });
    }
}

Passo 4: Ativando via Sistema

Vá até o painel Admin do Domain-System > Plugins, encontre seu Plugin na lista e clique em Ligar.

E pronto! O ecossistema fará a auto-descoberta e aplicará sua injeção no núcleo perfeitamente.
