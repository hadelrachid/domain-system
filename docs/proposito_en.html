The Story, The Purpose, and an Open Call to the Community

Why does this project exist?

Hi! My name is Hadel, and I am a self-taught developer. I started building Domain-System out of real-world frustration: why does launching a clean e-commerce store or an online school today require massive frameworks, hundreds of third-party dependencies, or CMS platforms that chew through hundreds of megabytes of RAM and break with every update?

I wanted to prove that modern, pure PHP 8.2+ can do much better: a modular, fast, bloat-free system that occupies just ~30 MB of disk space and uses only ~5 MB of RAM, running smoothly even on inexpensive shared hosting environments.

How it is built: Human craftsmanship and AI side-by-side

Because I am self-taught and build mostly on my own, I adopted modern AI models (Claude, ChatGPT, Nemotron, DeepSeek) as relentless daily code auditing partners. I design the architecture and write every line of logic; then, I set these models to audit the code line by line, hunting for security vulnerabilities, injection flaws, concurrency issues, and dead code.

For every issue found, I write regression tests in PHPUnit. Today, the project features a battle-tested suite of over 650 automated tests and nearly 4,000 assertions covering dropshipping, payment gateways, student enrollments, and security.

The limits of AI and why I need you

Let's be completely honest: AI only goes so far. It helps spot patterns, but nothing replaces the intuition, real-world production experience, and sanity checks of real human developers.

I don't claim to have all the answers or to be able to build a perfect system alone. That is why the code is 100% open source and I am making this open call to the developer community:

  • Code and Security Auditors: Come test, audit, and try to break the system to help us make it rock-solid.
  • Architecture Enthusiasts: Help me keep the code clean, decoupled, and simple, avoiding the temptation of overcomplicating what should be straightforward.
  • Contributors and Builders: Help build new plugins, lightweight visual themes, or run real-world stress tests.

What is the ultimate goal?

To keep an ultra-lightweight, resilient, and stable Core that simply handles dependencies, routes, and events, allowing anyone to launch and extend e-commerce stores, online schools, or websites without depending on bloated software or expensive monopolies.

If you share this vision for simple, fast, and transparent software, come join us on GitHub: github.com/hadelrachid/domain-system!
