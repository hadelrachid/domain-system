📦 DomainDrop — Dropshipping with AliExpress SDK

Autonomous E-Commerce Engine, 24h Flash Curation, Logistics Tracking & Customer Portal (v2.7.0)

Overview

DomainDrop (src/Plugins/domain_drop) is the official Dropshipping and Physical E-Commerce module in Domain-System v2.7.0. It integrates the Official AliExpress Open Platform SDK (TOP protocol with cryptographic HMAC-SHA256 signatures and OAuth 2.0 authentication) directly into our lightweight core (~30 MB), enabling a full-featured online store without bloated third-party platforms.

🚀 Key Capabilities

  • Official AliExpress Open Platform SDK Integration (AliExpressApiClientInterface):
    • Supports official AliExpress Open Platform APIs: product lookup (aliexpress.ds.product.get), curated recommendation feeds (aliexpress.ds.recommend.feed.get), freight calculation (aliexpress.logistics.buyer.freight.get), automated order placement (aliexpress.trade.buy.placeorder), and real-time logistics tracking (queryTrackingInfo).
    • Signed with HMAC-SHA256 and protected by an isolated external API Circuit Breaker.

  • Autonomous Mining & 24-Hour Flash Cycle (ProductMiningServiceInterface):
    • Smart product curation prioritizing local Brazil warehouse stock for fast delivery with automatic global fallback.
    • Dynamic currency conversion (USD → BRL) via CurrencyConverterInterface with configurable profit margins.
    • AI-powered copywriting enrichment (AiProductEnricherInterface) and a 24-hour flash rotation synchronized with the storefront countdown timer and HTTP anti-cache policies (CachePolicy).

  • Complete Customer Portal (/minha-conta, /entrar, /cadastro):
    • Dedicated customer authentication table (domain_drop_customers) strictly isolated from admin accounts.
    • 🛰️ Built-In Shipment Tracking: Interactive 5-stage delivery progress bar inside the customer account with direct links to Correios, Cainiao Global, and live AliExpress SDK tracking events.
    • 💬 Complaints, Notes & Questions: Ticket submission with secure photo/PDF evidence uploads (up to 4 files with magic-byte validation) and optional order or catalog product linking — allowing customers to reference a product or order code even before payment settlement.

  • Admin CRM, SLA Monitoring & Bilingual Supplier Mediation (/admin/dropship):
    • 👥 Customers & Buyers (/admin/dropship/customers): CRM view with search by name/email/CPF, order & ticket counters, account status toggles, and recent customer tickets.
    • 📦 Orders, SLA & Disputes (/admin/dropship/orders): Delivery SLA progress bars and a 1-click Supplier Mediation button (SellerMediationService) that automatically translates disputes into Simplified Chinese (zh-CN) for international suppliers (CN) or keeps Portuguese (pt-BR) for domestic suppliers (BR).

🏛️ Core Contracts (SOLID / DIP)

namespace DomainSystem\Plugins\domain_drop\Contracts;

interface AliExpressApiClientInterface        // Signed communication with AliExpress Open Platform SDK
interface ProductMiningServiceInterface       // 24h curation, BRL pricing & daily flash cycle
interface DropshipCatalogRepositoryInterface  // PDO catalog persistence (MySQL / SQLite)
interface DropshipOrderRepositoryInterface    // Order lifecycle & tracking codes
interface DropshipCustomerRepositoryInterface // Registered customers & CRM metrics
interface DropshipDisputeRepositoryInterface  // Customer tickets, complaints, notes & attachments

🎨 Native Theme Isolation vs. Flex Builder

Dedicated e-commerce themes such as rachidd_store declare "flex_builder": false in their theme.json. ThemeDiscoveryService::supportsFlexBuilder() automatically isolates the theme's native header and footer and displays an informational notice in the Flex Builder admin panel to prevent editing conflicts.
