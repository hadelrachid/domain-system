Domain-System OS

Guia Oficial de Construção de Extensões (Temas e Plugins)

Pré-requisito Crítico

Para construir para o Domain-System OS, você precisa entender os conceitos de Programação Orientada a Objetos (POO). O sistema não utiliza funções globais soltas. Tudo é baseado em Interfaces, Contratos, Classes e Encapsulamento.

O Fim da Bagunça Global

Se você vem do WordPress, está acostumado a criar um functions.php e usar funções globais. No Domain-System OS, isso é proibido.

Toda Extensão (Plugin ou Tema) é uma Classe que deve assinar um contrato chamado OsExtensionInterface. Esse contrato divide a vida do seu plugin em duas fases de segurança.

A Injeção de Dependências (O Garçom)

Aqui, você não procura por recursos do sistema instanciando variáveis aleatórias. O sistema funciona no modelo "Garçom": você senta, pede o que quer (Fase 1), e o Sistema Operacional injeta a ferramenta pronta na sua mão (Fase 2).

Fase 1: Negociação (osRegister)

Antes de rodar qualquer regra de negócio, você usa o objeto OsConnector para avisar ao Sistema Operacional o que você vai precisar usar. Se você não pedir permissão aqui, será bloqueado na Fase 2.

public function osRegister(OsConnector $os): void
{
    // Pedindo permissão para ler dados de usuários
    $os->requireLink('auth.user_reader');
    
    // Pedindo permissão para criar um widget na tela
    $os->requestSlot('admin.dashboard.alerts');
}

Fase 2: Execução (osBoot)

Depois de aprovar seu contrato, o Sistema Operacional te passa o OsRuntime. É aqui que você trabalha, recebendo os recursos que requisitou com Injeção de Dependências.

public function osBoot(OsRuntime $runtime): void
{
    // O SO Injeta a ferramenta na sua mão
    $userReader = $runtime->getLink('auth.user_reader');
    
    // Agora podemos injetar nosso visual na tela (Slot)
    $runtime->contributeTo('admin.dashboard.alerts', [
        'message' => 'Plugin inicializado com sucesso!'
    ]);
}

Estrutura Completa de um Plugin/Tema

Basta criar a sua classe implementando a Interface. O Kernel do Domain-System OS fará todo o resto automaticamente.

namespace DomainSystem\Plugins\meu_plugin;

use DomainSystem\Core\Plugin\AbstractPlugin;
use DomainSystem\Core\Contracts\OsExtensionInterface;
use DomainSystem\Core\Plugin\OsConnector;
use DomainSystem\Core\Plugin\OsRuntime;

class Plugin extends AbstractPlugin implements OsExtensionInterface
{
    public function osRegister(OsConnector $os): void
    {
        $os->requireLink('core.session');
    }

    public function osBoot(OsRuntime $runtime): void
    {
        $session = $runtime->getLink('core.session');
        // Seu código seguro e isolado vai aqui!
    }
}
