Construindo Apps no Web OS (v2.1)

O Domain System agora orquestra Plugins no Ring 3 usando estritamente Contratos e Interfaces. Siga este tutorial definitivo para criar o seu primeiro App (Plugin) moderno, completo com Widgets de Dashboard e Permissões de Segurança (ACL).

Atenção: Nunca injete HTML sujo nos Hooks do sistema (como era feito no antigo OS 1.0). Todos os componentes vitais agora exigem Providers e Interfaces.

Passo 1: A Estrutura Base (plugin.json)

Crie uma pasta em src/Plugins/meu_app e adicione o plugin.json:

{
    "name": "meu_app",
    "version": "1.0.0",
    "description": "Um App Moderno para o Web OS",
    "author": "Sua Empresa",
    "os_version": "2.1"
}

Passo 2: A Classe Plugin (O Coração)

O arquivo Plugin.php deve implementar a fase de Negociação (Gatekeeper), Execução (Boot) e Instalação (Activate).

namespace DomainSystem\Plugins\meu_app;

use DomainSystem\Core\Plugin\AbstractPlugin;
use DomainSystem\Core\Contracts\OsExtensionInterface;
use DomainSystem\Core\Contracts\OsConnectorInterface;
use DomainSystem\Core\Contracts\OsRuntimeInterface;

class Plugin extends AbstractPlugin implements OsExtensionInterface
{
    public function register(): void {}

    // FASE 1: NEGOCIAÇÃO
    public function osRegister(OsConnectorInterface $os): void
    {
        $os->requireLink('core.identity'); // Pede permissão à ACL
        $os->listenHook('dashboard.register_widgets'); // Pede para criar um Widget
    }

    // FASE 2: EXECUÇÃO (Runtime)
    public function osBoot(OsRuntimeInterface $runtime): void
    {
        $identity = $runtime->getLink('core.identity');
        
        $runtime->onHook('dashboard.register_widgets', function($registry) use ($identity) {
            $registry->registerProvider(new MeuWidgetProvider($identity));
        });
    }

    // FASE 3: INSTALAÇÃO (Só roda quando o Admin clica em Instalar)
    public function activate(OsRuntimeInterface $runtime): void
    {
        // Cria a permissão no Banco de Dados para o menu "Controle de Acessos"
        $runtime->registerCapability('meu_app.acessar', 'Módulo Meu App');
    }
}

Passo 3: Criando o Widget Profissional (O Provider)

No novo padrão corporativo do OS, você não ejeta HTML no vazio. Você cria um Contrato de Fornecedor de Widgets (DashboardWidgetProviderInterface). Crie o arquivo MeuWidgetProvider.php na pasta do seu plugin:

namespace DomainSystem\Plugins\meu_app;

use DomainSystem\Core\Contracts\DashboardWidgetProviderInterface;
use DomainSystem\Core\Security\IdentityManager;

class MeuWidgetProvider implements DashboardWidgetProviderInterface
{
    private IdentityManager $identity;

    public function __construct(IdentityManager $identity)
    {
        $this->identity = $identity;
    }

    public function getProviderName(): string
    {
        return 'Meu App Widgets';
    }

    public function getAvailableWidgets(): array
    {
        return [
            'meu_grafico' => [
                'title' => 'Gráfico de Vendas',
                'description' => 'Visualização de Vendas Mensais'
            ]
        ];
    }

    public function renderWidget(string $widgetId): string
    {
        if ($widgetId === 'meu_grafico') {
            $userId = $_SESSION['auth_user_id'] ?? 0;
            
            if (!$this->identity->userCan($userId, 'meu_app.acessar')) {
                return '<div class="error">Acesso Negado pela ACL</div>';
            }
            
            return '<h3>Seu gráfico aqui!</h3>';
        }
        return '';
    }
}

E pronto! O seu plugin é um cidadão de primeira classe do Web OS, perfeitamente blindado, validado e documentado.
