Construindo Plugins no Domain System (v2.7.0)

Criar um plugin no Domain System v2.7.0 é simples, direto e sem mágica escondida. Como desenvolvedor autodidata, projetei o sistema para ser o mais enxuto e transparente possível. Não usamos frameworks gigantescos nem centenas de pacotes de terceiros: tudo roda em PHP limpo, com contratos bem definidos e uma arquitetura orientada a eventos.

Neste tutorial passo a passo, você vai aprender a construir um plugin do zero, com:

  • Estrutura de arquivos e manifesto plugin.json;
  • Ciclo de vida (osRegister, osBoot, activate, deactivate);
  • Criação de rotas HTTP públicas e privadas;
  • Registro de menu no Cockpit Administrativo;
  • Criação de tabelas no banco de dados de forma agnóstica;
  • Widgets de dashboard e documentação com auto-descoberta no Manual.
Regra de Ouro da Arquitetura: Nunca injete HTML sujo nos Hooks do sistema nem acesse superglobais ($_SESSION, $_POST) diretamente. Todos os componentes do ecossistema Domain utilizam Providers e Interfaces para garantir segurança e testabilidade com 100% de cobertura.

Passo 0: Atalho via CLI ou com Suporte de I.A.

Você pode criar o esqueleto do seu plugin em segundos usando o comando de console:

php os-cli.php make:plugin meu_app

Se você usa ferramentas de Inteligência Artificial (GitHub Copilot, Cursor, Gemini, Claude ou Cline), consulte o nosso Guia de Contratos para IA para gerar plugins perfeitamente compatíveis de primeira.

Passo 1: A Estrutura de Pastas e o plugin.json

Crie uma pasta em src/Plugins/meu_app. O ponto de partida é o arquivo de manifesto plugin.json:

{
    "name": "meu_app",
    "version": "1.0.0",
    "description": "Meu primeiro módulo no Domain System v2.7.0",
    "author": "Seu Nome ou Comunidade",
    "os_version": "2.7"
}

Passo 2: A Classe Principal (Plugin.php)

A classe Plugin.php gerencia as fases de Negociação (osRegister), Execução (osBoot) e Instalação (activate).

<?php
namespace DomainSystem\Plugins\meu_app;

use DomainSystem\Core\Plugin\AbstractPlugin;
use DomainSystem\Core\Contracts\OsExtensionInterface;
use DomainSystem\Core\Contracts\OsConnectorInterface;
use DomainSystem\Core\Contracts\OsRuntimeInterface;

class Plugin extends AbstractPlugin implements OsExtensionInterface
{
    // 1. NEGOCIAÇÃO: Declara dependências e hooks ouvidos
    public function osRegister(OsConnectorInterface $os): void
    {
        $os->requireLink('core.identity');
        $os->requireLink('core.database');
        $os->listenHook('admin_menu.register');
        $os->listenHook('dashboard.register_widgets');
    }

    // 2. EXECUÇÃO: Registra rotas, menus e ouve eventos
    public function osBoot(OsRuntimeInterface $runtime): void
    {
        // Registra uma rota pública no sistema
        $runtime->addRoute('GET', '/meu-app', function() {
            return '<h1>Olá mundo do Plugin Meu App!</h1>';
        });

        // Adiciona um item no menu do painel administrativo
        $runtime->onHook('admin_menu.register', function(&$menuItems) {
            $menuItems[] = [
                'title' => 'Meu App',
                'url'   => '/admin/meu-app',
                'icon'  => 'box'
            ];
        });

        // Registra um widget no Dashboard
        $identity = $runtime->getLink('core.identity');
        $runtime->onHook('dashboard.register_widgets', function($registry) use ($identity) {
            $registry->registerProvider(new MeuWidgetProvider($identity));
        });
    }

    // 3. INSTALAÇÃO: Executado apenas uma vez ao clicar em Ativar
    public function activate(OsRuntimeInterface $runtime): void
    {
        $db = $runtime->getDb();
        $db->exec("CREATE TABLE IF NOT EXISTS ds_meu_app_itens (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            titulo VARCHAR(255) NOT NULL,
            created_at DATETIME DEFAULT CURRENT_TIMESTAMP
        )");

        // Registra a permissão no controle de acessos (ACL)
        $runtime->registerCapability('meu_app.acessar', 'Módulo Meu App');
    }

    public function deactivate(OsRuntimeInterface $runtime): void {}
    public function uninstall(OsRuntimeInterface $runtime): void {}
}

Passo 3: Criando o Widget do Dashboard (MeuWidgetProvider.php)

Para adicionar caixas e resumos no painel sem injetar HTML no vazio, implemente DashboardWidgetProviderInterface:

<?php
namespace DomainSystem\Plugins\meu_app;

use DomainSystem\Core\Contracts\DashboardWidgetProviderInterface;
use DomainSystem\Core\Contracts\SessionManagerInterface;
use DomainSystem\Core\Security\IdentityManager;

class MeuWidgetProvider implements DashboardWidgetProviderInterface
{
    private IdentityManager $identity;
    private ?SessionManagerInterface $session;

    public function __construct(IdentityManager $identity, ?SessionManagerInterface $session = null)
    {
        $this->identity = $identity;
        $this->session = $session;
    }

    public function getProviderName(): string
    {
        return 'Meu App Widgets';
    }

    public function getAvailableWidgets(): array
    {
        return [
            'resumo_meu_app' => [
                'title' => 'Status do Meu App',
                'description' => 'Métricas e avisos rápidos'
            ]
        ];
    }

    public function renderWidget(string $widgetId): string
    {
        if ($widgetId === 'resumo_meu_app') {
            $userId = (int)($this->session?->get('auth_user_id', 0) ?? 0);
            
            if (!$this->identity->userCan($userId, 'meu_app.acessar')) {
                return '<div class="error">Acesso restrito.</div>';
            }
            
            return '<div class="card"><h4>Meu App Ativo!</h4><p>Tudo operando normalmente.</p></div>';
        }
        return '';
    }
}

Passo 4: Auto-Descoberta no Manual de Instruções (manual/module.php)

No Domain System v2.7.0, você não precisa editar o core para ter documentação do seu plugin. Basta criar o arquivo src/Plugins/meu_app/manual/module.php retornando uma classe que implemente ManualModuleInterface:

<?php
// src/Plugins/meu_app/manual/module.php
require_once __DIR__ . '/MeuAppManualModule.php';

return new \DomainSystem\Plugins\meu_app\manual\MeuAppManualModule();

O PluginManualScanner detecta seu módulo automaticamente e o insere no menu Manual de Instruções (/admin/manual) com seu checklist de homologação e guia interativo!
